# 🐍 Python Projects

A collection of beginner-to-intermediate Python command-line projects I built while learning Python. They cover file handling, JSON/Excel persistence, REST APIs, web scraping, encryption, and data visualization.

## 📂 Projects

| Project | What it does | Concepts |
|---|---|---|
| [Computer Quiz Game](Computer%20Quiz%20Game.py) | Interactive quiz with score tracking | Dictionaries, loops, JSON (`scores.json`) |
| [Daily Life Tracker](Daily%20Life%20Tracker.py) | Logs daily activities to an Excel workbook | `openpyxl`, `datetime`, file I/O |
| [Expense Tracker](Expense%20Tracker.py) | Add expenses and view running totals | Lists, tuples, menu-driven CLI |
| [Life Energy Dashboard](Life%20Energy%20Dashboard.py) | Tracks daily energy levels and plots trends | JSON, `matplotlib` |
| [Password Manager](Password%20Manager.py) | Stores passwords encrypted with a local key | `cryptography.fernet`, `getpass` |
| [Smart File Organizer](Smart%20File%20Organizer.py) | Sorts files in a folder into sub-folders by type | `os`, `shutil` |
| [Weather API System](Weather%20API%20System.py) | Fetches weather for a city and saves it as JSON | `requests`, REST APIs, JSON |
| [Web Scraper (BBC News)](Web%20Scraper%20(BBC%20News).py) | Scrapes the latest BBC News headlines | `requests`, `BeautifulSoup` |

## 🚀 Getting started

```bash
git clone https://github.com/alirazasaleem-1/Python-Projects.git
cd Python-Projects
pip install -r requirements.txt
python "Expense Tracker.py"
```

Each script is standalone. Run any of them with `python "<script name>.py"`.
